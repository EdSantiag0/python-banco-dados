# 🛒 Sistema de Controle de Produtos (Python + SQLite)

Projeto desenvolvido para praticar manipulação de banco de dados utilizando Python e SQLite.

## 🚀 Funcionalidades

- ✅ Cadastrar produto
- ✅ Listar produtos
- ✅ Atualizar produto
- ✅ Deletar produto

## 🧠 Tecnologias utilizadas

- Python
- SQLite3

## 📂 Estrutura do projeto

database/
models/
main.py
loja.db

## ▶️ Como executar

1. Clone o repositório:

git clone https://github.com/EdSantiag0/python-banco-dados

2. Acesse a pasta:

cd python-banco-dados

3. Execute o projeto:

python main.py

## 📸 Exemplo de uso

Ao executar o main.py as intruções de uso do programa estarão no terminal.
